# Kad Gagasan PEMBINA

Kit rujukan Penggerak Dakwah untuk Hard Pitch. Satu fail HTML — tiada pemasangan.

Tiga tab: **Visi & Misi** · **Objektif** (Strategik PEMBINA 2024–2026 + PSPB 2026) · **Gagasan** (kad produk, boleh tapis ikut gagasan). Butang *Cetak semua* mencetak kesemua tab.

## Terbit di GitHub Pages
1. Buat repository baru (cth: `kad-gagasan`).
2. Namakan fail ini **`index.html`**, kemudian **Add file → Upload files** → seret masuk `index.html` + `README.md` → **Commit**.
3. **Settings → Pages** → *Deploy from a branch* → **main** / **root** → **Save**.
4. Pautan: `https://<username>.github.io/kad-gagasan/`

Bahan rujukan sahaja — tiada data yang disimpan.
